常见问题

1. App 是否需要联网？

不需要。本应用为离线单机版，首次启动后题库已拷贝到设备本地，全程无需联网即可使用。订阅购买与恢复购买需要联网（走 Apple StoreKit）。

2. 如何开通 VIP？

打开 App → 底部「设置」Tab →「开通 VIP」→ 选择月度 / 季度 / 年度订阅档位 → 通过 Apple ID 完成支付。开通后立即解锁全部套卷、模拟组卷与无限制练习。

3. 如何取消订阅？

iOS「设置」→ 顶部 Apple ID 头像 →「订阅」→ 找到「计算机专业考编题库」→ 点「取消订阅」。取消后当前订阅期内继续享受 VIP 权益，到期后自动恢复为免费版。

4. 更换手机后 VIP 还有效吗？

有效。在同一 Apple ID 登录新设备后，打开 App → 设置 → 开通 VIP → 页面顶部「恢复购买」即可同步订阅状态。

5. 题库多久更新一次？

不定期更新，一般每季度一次。VIP 用户在订阅有效期内可免费获取题库内容更新，免费版用户可继续使用当前题库，不强制升级。

6. 题库内容来源？

题库内所有题目均由团队依据公开考试大纲自行编写整理，非任何官方出版物内容，也不复制任何已发表的试卷原文。题目仅作为学习练习用途。

7. 学习数据如何备份？

当前版本暂不支持云端备份。学习记录（错题本、收藏、笔记、练习历史）保存在设备本地，卸载 App 会清空，请谨慎操作。云端备份功能将在后续版本提供。

8. 题库能否导出到电脑？

当前版本不支持导出。题库以 SQLite 形式内置在 App 沙盒内，受 iOS 沙盒机制保护，无法直接读取。如确有导出需求，可在「设置」页反馈，我们评估后续版本支持。

退款说明

本应用所有订阅均通过 Apple App Store 完成支付，款项由 Apple 直接收取，开发者无法直接办理退款。如需申请退款，请通过 Apple 官方渠道：

  1. 访问 reportaproblem.apple.com
  2. 登录付款时所用的 Apple ID
  3. 找到对应订阅订单 →「报告问题」→ 选择原因
  4. Apple 客服会在 24-48 小时内审核回复
